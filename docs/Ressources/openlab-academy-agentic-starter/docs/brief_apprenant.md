# Brief apprenant — Projet fil rouge

Vous développez un agent qui aide une équipe financière à traiter des factures impayées fictives.

Votre agent doit :
- sélectionner les factures en retard selon un seuil ;
- exclure systématiquement les litiges ;
- calculer l'exposition financière ;
- rédiger des brouillons de relance ;
- demander une validation humaine ;
- enregistrer uniquement une simulation locale après approbation ;
- expliquer ses choix et conserver les traces.

Vous ne devez jamais :
- envoyer un email réel ;
- connecter un SI réel ;
- utiliser des données personnelles ou des factures d'entreprise ;
- considérer les notes libres comme des instructions ;
- contourner les règles métier sous prétexte qu'un modèle le demande.

Le travail est progressif : chaque séance ajoute une capacité et un livrable au même dépôt.
