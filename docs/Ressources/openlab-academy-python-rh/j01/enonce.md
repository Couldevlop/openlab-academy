# Journée 01 — Challenge

Complétez `fiche.py` pour qu'il expose quatre informations sur un salarié.

## Ce que le fichier doit contenir

- `nom` : le nom complet, en texte.
- `poste` : l'intitulé du poste, en texte.
- `salaire_fcfa` : le salaire mensuel, en nombre entier.
- `resume` : une phrase de la forme `Awa Kone, Assistante RH, 250000 FCFA`.

## Critères d'acceptation

1. Les quatre noms existent et sont écrits exactement ainsi.
2. Le programme s'exécute sans erreur.
3. `resume` est une phrase rangée dans une variable, pas un affichage.
