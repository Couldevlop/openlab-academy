# Journée 02 — Challenge

Écrivez deux fonctions dans `calculs.py`.

## Ce qu'il faut écrire

- `salaire_annuel(mensuel, primes)` : douze fois le salaire mensuel, plus le total des primes.
  Rend un nombre entier. `primes` est une liste, éventuellement vide.
- `formater_fcfa(montant)` : rend une chaîne comme `3 250 000 FCFA`, séparée par des espaces
  insécables, sans décimale.

## Critères d'acceptation

1. `salaire_annuel` rend un entier, jamais un flottant.
2. `formater_fcfa` rend une chaîne qui se termine par ` FCFA`.
3. Aucune des deux fonctions n'affiche quoi que ce soit.
