# Journée 03 — Challenge

Écrivez `droit_aux_conges(mois_anciennete)` dans `conges.py`.

## La règle de l'entreprise

Le droit aux congés s'ouvre à douze mois d'ancienneté révolus. Avant, aucun droit.

## Critères d'acceptation

1. La fonction rend un booléen, `True` ou `False`.
2. Une ancienneté négative lève une `ValueError` : c'est une donnée fausse, pas un cas métier.
3. La règle est écrite une seule fois.
