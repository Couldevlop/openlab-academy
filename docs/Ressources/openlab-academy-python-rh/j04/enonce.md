# Journée 04 — Challenge

Écrivez `masse_salariale(salaires)` et `plus_haut_salaire(salaires)` dans `paie.py`.

## Ce qu'il faut écrire

- `masse_salariale(salaires)` : la somme de la liste. Sur une liste vide, rend `0`.
- `plus_haut_salaire(salaires)` : le salaire le plus élevé. Sur une liste vide, lève une
  `ValueError` : un plus haut salaire n'existe pas dans un effectif vide.

## Critères d'acceptation

1. Les deux fonctions sont écrites avec une boucle, sans `sum` ni `max`.
2. Les trois cas limites passent : liste vide, un seul élément, deux salaires ex aequo.
3. Aucune des deux fonctions n'affiche quoi que ce soit.
