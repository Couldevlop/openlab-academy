# Journée 13 — Challenge

Faites lever `DonneeInvalide` par votre chargement, dans les trois cas :

1. fichier absent : le message nomme le fichier cherché ;
2. colonne manquante : le message nomme la colonne ;
3. salaire illisible : le message nomme la ligne fautive.

## Critères d'acceptation

1. Aucun `except` nu dans le projet ; chaque `except` nomme son type.
2. Chaque message dit quoi corriger.
3. Une erreur de programmation continue de remonter telle quelle.
