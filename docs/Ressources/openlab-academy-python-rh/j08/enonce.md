# Journée 08 — Challenge

Écrivez `par_poste(effectif)` et `filtrer_par_salaire(effectif, mini)` dans `effectifs.py`.

## Ce qu'il faut écrire

- `par_poste(effectif)` : rend un dictionnaire `{poste: [noms]}`.
- `filtrer_par_salaire(effectif, mini)` : rend la liste des fiches dont le salaire atteint le
  minimum, borne comprise.

## Critères d'acceptation

1. Aucune des deux fonctions ne modifie l'effectif reçu.
2. Le filtre inclut la valeur exacte du minimum.
3. Les deux fonctions rendent une valeur, elles n'affichent rien.
