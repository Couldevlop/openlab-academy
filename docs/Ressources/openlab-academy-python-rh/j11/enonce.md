# Journée 11 — Challenge

Rangez votre code en trois fichiers.

```
rh/calculs.py   les calculs, qui n'importent rien du projet
rh/etats.py     la mise en forme, qui importe les calculs
main.py         le point d'entrée, protégé par la garde
```

## Critères d'acceptation

1. Les trois fichiers existent à ces emplacements exacts.
2. Importer un module n'affiche rien.
3. `rh/calculs.py` n'importe aucun autre module du projet.
